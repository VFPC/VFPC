# UK VFPC

UK VFPC (UK VATSIM Flight Plan Checker) is a EuroScope plugin that checks filed IFR flight
plans against UK departure restrictions from the SRD.

**N.B.** - This plugin does not negate or replace the need for Delivery controllers to
thoroughly check each Flight Plan before issuing a clearance.

## Download

Get the latest plugin from the **[Releases page](https://github.com/VFPC/VFPC/releases/latest)**.

## Documentation

The user guide (installation, setup, tag codes and chat commands) is online at
**[vfpcdata.org/docs](https://vfpcdata.org/docs/)**.
